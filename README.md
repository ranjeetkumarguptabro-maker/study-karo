# 📚 Study Karo - 15-Day Study & Learn Masterclass

An educational website offering online tutoring, courses, and learning resources across **Mathematics**, **Science** (Physics, Chemistry, Biology), and **Commerce** (Financial Accounting, Business Studies & Economics).

- **Lead Educator & Teacher**: Krish Mallick ([krishmallick077@gmail.com](mailto:krishmallick077@gmail.com))
- **Tech Stack**: React 18, Vite, Three.js, Lucide React, Canvas Confetti

## 🚀 Key Features

- **Maths, Science & Commerce Subject Hubs**: Deep-dive curriculum and visual learning modules.
- **15-Day Study Roadmap**: Day-by-day structured curriculum with daily practice problem sets (DPP).
- **Interactive Learning Lab**:
  - Maths Quadratic Equation Solver & Discriminant Explorer
  - Science Ohm's Law & Electrical Circuit Simulator
  - Commerce Double Entry Ledger & Golden Rules Simulator
- **Score Booster Calculator**: Estimates score improvement from current marks to target 90%+ in board exams.
- **Small Batch Live Mentorship**: Free demo booking & 15-day batch enrollment.
- **3D Interactive Background**: Animated Three.js geometry.

## 🛠️ Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
